# Start Here

AI Engineering Workbench v0.1 investigates committed Git history through a selected
Codex CLI connection and produces evidence-backed, versioned reports.

- **Install and launch:** follow the [README quick start](README.md#quick-start).
- **Use the application:** follow the [user guide](docs/user-guide.md), including
  the practice case, connection setup, investigation, challenge and export.
- **Operate, back up or upgrade:** use the [Linux guide](docs/linux-demo.md).
- **Review the verified scope:** read [release acceptance](docs/release-acceptance.md)
  and [known issues](docs/open-issues.md).
- **Contribute:** read [AGENTS.md](AGENTS.md) and the
  [development section](README.md#documentation-and-development).

Creating fixtures, setting up a workspace and preparing worktrees make no model
requests. **Run investigation** and **Challenge and run** invoke your configured
CLI. Explicitly select the intended configuration directory before creating tasks.
