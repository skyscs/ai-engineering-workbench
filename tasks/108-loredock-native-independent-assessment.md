# Task 108 — Assess native results independently

Status: implementation started, 2026-11-04.

Implement a bounded offline assessment boundary for the actual native v2 projection,
native catalog-bound receipt and authorized recorded-history output. It must not
import production codecs, path resolvers or capture services, relabel an experimental
schema, authorize current source access or execute source content. Retain all old
experimental evaluators and frozen measured inputs/results unchanged.

Validate raw UTF-8, exact schemas/keys, nesting/byte bounds, catalog and content
identities, graph/flow/support structure, native topic witnesses and original/dependency
vectors. Compare original text, line ranges, content hashes and Git blob identities
with independent caller-owned expected sources. Preserve artifact bytes and independent
results even if another dimension fails: integrity, shape, source support, usefulness,
historical equality and raw repeat/parity are separate. Missing required input must
fail or remain explicitly blocked, never silently reduce a denominator. Current
catalog authorization and execution applicability are not evaluated offline.

Use fresh small owned sources and actual compiled NativeCaptures outputs as positive
inputs. Cover default, selected, isolated and root-page projections, duplicate bytes,
restart and inventory-evicted history. Include an independently authored incomplete
consumer example whose gap is valid but cannot pass the complete-flow oracle. Mutate
saved copies for unsupported schemas, invalid UTF-8, unknown nested fields, rehashed
inconsistent identities/witnesses/ranges, missing undisplayed dependencies, unrelated
originals, altered text and mismatched history. Refuse unsafe artifact references and
bounded-read races. The production decoder must not be the assessment oracle.

This task establishes the functional assessor, not a new resource family. Retain first
failures, run focused/full checks and a compiled lifecycle smoke, document the independent
boundary and review every accepted text/identity. Next scope the native compiled worker
and coordinator against this assessor before freezing final composition qualification.
The unchanged gate remains sixteen complete operations in two processes, seven raw
cross-process comparisons, 5,000 ms/1,000,000 work units, 150 ms sampled intervals,
384 MiB RSS, 64 MiB heap growth and all existing output/support limits. No HTTP/browser,
answer/review consumer, model/corporate data or L5 promotion is part of this task.
