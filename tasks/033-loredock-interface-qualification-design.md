Status: in progress. Follows Task 032 / merged PR #36 (`22f29bf`).

## Scope and acceptance

1. Define a new synthetic twenty-repository corpus and fourteen prospective questions
   before inspecting any new model output. Use different domain/header/handler names
   from Tasks 030–032. Keep all earlier corpora, contracts and scores unchanged.
2. Cover case-only matches, renamed/punctuation differences, dynamic/spread/getter inputs,
   empty headers, conversion uncertainty, an explicit but unwired rewrite helper and
   exact binding ownership. Include fresh documentation-conflict, interface-boundary,
   environment-scope and untrusted-source regression cases.
3. Freeze source bytes, deterministic revisions, original evidence locators, questions,
   required propositions/qualifications and forbidden assertions before evaluation.
   Expected answers and scoring stay outside every registered source repository and
   never enter production inputs. Disclose same-agent authorship and synthetic limits;
   this is prospective conformance coverage, not a blind or private-project benchmark.
4. Measure unchanged retrieval v7 / prompt v9 on two fresh generations, including exact
   original ownership/bytes/ranges, reference availability, comparison admission and
   prompt bounds. A missing recorded reference is diagnostic, not an automatic semantic
   failure if equivalent evidence exists. Do not tune the product in this task.
5. Specify one future run of at most fourteen application attempts, no automatic retry,
   fixed qualified runtime/model/effort and frozen implementation contract before dispatch.
   Every claim and unknown needs semantic review; all required facts/qualifications and
   extra claims count. The old failed gates remain failed regardless of this run.
6. Add focused fixture/evaluator tests, run full checks, record results and next conditions,
   review and merge after both exact-head CI runs pass. No product/UI/runtime changes;
   no real model call in Task 033. Continue to the separately bounded execution phase
   after merge under the owner's explicit instruction to proceed without another prompt.
