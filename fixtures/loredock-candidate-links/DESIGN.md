# Source candidate links v1 — frozen design

Task 037 adds a separate reading aid to the Task 036 lexical shortlist. Freeze
this document and the adversarial cases before implementing or measuring it.
Do not change lexical ranking, answer retrieval, prompts, model budgets or old reports.

1. Only primary lexical suggestions are seeds. Inspect the existing bounded code
   and declaration projections for the same authorized index. No new parser or
   repository-specific mapping is introduced.
2. Admit cross-source `http-target` and `event-delivery` code edges, and declaration
   `contract-match`, `contract-difference`, `setting-match`, `setting-difference` edges.
   A seed endpoint must own an original passage that is both in the unchanged
   question context and contains a distinctive question term under the existing
   normalization. Edge-level auxiliary evidence cannot supply this anchor.
3. Only direct neighbors outside the primary suggestions are added. Preserve edge
   direction, status, scope, reason and gaps. Differences stay differences; equal
   declarations remain unverified clues. Never traverse a second hop, infer a
   service identity or replace the lexical shortlist with graph reachability.
4. Include at most four additional repositories, in saved source order, and two
   relationships per repository. Order links by kind in the order in rule 2, then
   canonical original endpoint/support locators and endpoint labels. Never use
   random graph/source/evidence IDs as a tie breaker. Report eligible and omitted
   source/link counts. Limits are reading budgets, not confidence thresholds.
5. Each relationship retains all original evidence from both endpoints and the
   edge. Validate source ID/name/revision, build, hashes and ranges against the
   authorized catalog. Keep each endpoint's own support distinct from auxiliary
   support. Missing or foreign original evidence fails closed. No derived graph
   identifier becomes a citation. Additional originals are for this preview only;
   they do not alter the answer context or its input hash.
6. Include projection versions, hashes, coverage, omissions and uncertainty in the
   preview hash. Engineer notes overlapping either lexical or linked originals
   remain separate unverified assertions. Empty results mean no admitted link in
   this bounded supported analysis, never proof that a repository is unrelated.
7. The UI shows the links separately, with the seed, both endpoints and original
   evidence controls. Retain question/index/source/policy/review response fences,
   escape all labels, and support keyboard and narrow screens. No AI setup or calls.

Evaluate two fresh synthetic generations against the already observed Task 035
incidents. Retain Task 036 selection hashes and Task 035 context selections, report
union recall and expanded counts separately, including failures and scope inflation.
This is development diagnostics, not blind acceptance or automatic routing. No
corporate code, new model dispatch, new storage schema or Workbench bridge.
