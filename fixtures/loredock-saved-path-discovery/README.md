# Saved-path discovery controls

The [baseline](baseline.json) was captured after PR #121 acceptance and before native
listing changes. It binds the accepted 38-module actual runtime, source/emitted bytes
of the three possible native touch points, and existing emitted class members. It uses
the actual Node/V8 and TypeScript versions recorded in the file.

Adding listing changes the runtime closure. Existing capture/history/storage methods
must retain their emitted bodies; the CaptureWork authorization input may use a narrower
type without changing its emitted authority checks. Runtime/source identity comparison
is a change control, not a substitute for actual lifecycle/authorization tests or a claim
that prior resource qualification transfers to added code.

This is not a reserved resource family. No source corpus or runtime result has been
selected from observed listing measurements. Task 118's prospective contract defines
the ordinary small/full-capacity checks separately. Preserve this baseline and first
subsequent failures; do not rewrite it to match the implementation.
