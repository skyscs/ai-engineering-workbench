# Task 075 — Frozen shared capture scale qualification

Freeze this directory before candidate implementation or observation. The owned twenty-source
sensor corpus and expected relations are authored from source bytes, not parser/path output.
They are known to the author and are not blind external or semantic/private-pilot review.
No earlier frozen matrix or measured candidate may be edited or rerun.

## One-run protocol

1. Commit all input bytes, oracle and protocol, then implement the separate candidate and
   independent small regressions. Do not import this corpus/probe into CI or inspect it
   through the candidate during development. Commit the final measured candidate/observer.
2. Record full HEAD, every input SHA-256, source-fork identities, Node/hardware and a fresh
   exclusive absolute result directory. Run this matrix once, without parallel heavy checks.
3. Prepare each size once in ascending order, reporting source/index/analysis preparation
   time and admitted counts separately. Index/analysis may resume explicit paused work within
   their existing caps; no raised bounds. Capture first/repeat, selected and isolated roots;
   journal root-page reads. First/repeat receipt bytes and IDs must agree. Then evict the old
   inventory through two explicit analyses, restart and read its exact old receipt without
   path/fact/Git/catalog writes. The resource interval starts before each capture/read call.
4. For each successful operation record outer wall, 5 ms timer samples plus a final interval,
   sampled RSS/heap growth, complete bytes/spans/dependencies and phase charge deltas. Require
   all oracle bounds, exact total = path + receipt work and independent observed delta sums.
   History has zero path work. Reopen every original and compare its exact source text/range/
   hashes, not only display snippets. Keep path/receipt local limits independently active.
5. On each size, after the first capture, exercise the frozen diagnostic formula
   `shared ceiling = max(first.pathWork, first.receiptWork)`. Both recorded subtotals fit this
   reduced ceiling but their sum exceeds it; the same request must refuse before publication.
   This adaptive fault value is specified prospectively and is not a tuned resource threshold.
   Preserve the prior receipt and require a subsequent unrestricted repeat to recover its ID.
6. Run each named variant once in a fresh small twenty-source catalog. Positive variants keep
   the specified number of full write-ending paths; comparison pressure keeps at least one
   completed write path while reporting both comparison and traversal omissions. Negative
   cases require their exact relevant reason, never a generic nonempty gap map. Validate full
   originals even for partial/negative projections. Long support exceeds 35,000 original bytes
   while fitting all unchanged per-file/span/receipt bounds. No support is trimmed to fit.
7. Exercise budget/deadline/cancellation at every path stage and receipt stage using small
   fresh fixtures. Trusted diagnostic hooks may attempt one over-limit charge, await the
   original absolute deadline, or abort the signal. Record injected charge attempts separately;
   these are refusal diagnostics, not resource successes. Require that each selected stage was
   reached, normalized refusal, no new file/pending output and clean reader/budget ownership.
   Reused/closed budgets and invalid/increased limits are covered by independent regressions.
8. Test a committed external SQLite write before handoff and a competing writer under the
   final guard. Test synchronous cancellation after linking a new target and an identical
   existing target: remove only the owned new target/pending file, preserve existing bytes.
   Async publication hooks are forbidden. A cleanup/observer exception never counts as an
   expected domain refusal. Count lifecycle writes only inside their explicit fixture hooks.
9. On separate small catalogs, run each listed history mutation after a complete capture.
   Eviction/restart preserve exact bytes; cited/uncited revocation, policy and corrupt originals
   refuse history without deriving paths/facts. Source commits and existing answer/correction
   rows remain unchanged by the measured operations. No model invocation is permitted.
10. Journal exact raw projections/receipts/normalized errors immediately after return, before
    assertion, resource or mutation checks. Preserve raw edited artifacts and initial stdout/
    stderr/exit. Identify expected nodes by source/path/kind/label/role with exact cardinality.
    Continue independent cases after failure only if owned cleanup succeeds; mark later checks
    blocked by a failed prerequisite as unexecuted, never passed. Preserve the first failure.

## Gates and limits

All useful-path, support/authorization, shared-budget, resource, history and observer gates
are mandatory. A failed gate rejects promotion; do not revise this oracle or rerun the matrix.
Use a new prospective successor if needed. Resource thresholds remain 5,000 ms cooperative
outer time, 1,000,000 aggregate work units, 150 ms maximum sampled interval, 384 MiB sampled
RSS and 64 MiB heap growth. Input/index preparation is outside these operation measurements.
Sampling is not a peak-memory guarantee; synchronous I/O is not interruptible mid-call.

Keep two default paths/twenty steps, 160 display nodes/240 edges, 512 KiB projection, thirty
originals/64 KiB text, 640 KiB receipt and twenty source dependencies. The shared accounting
changes no literal-topic predicate, original-support rule or production consumer. Passing
permits only a separate integration review, not semantic acceptance or automatic routing.
