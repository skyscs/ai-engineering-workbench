## Proposal

For every eligible related source, take its strongest already admitted relationship kind
under the existing within-source ordering: HTTP target, event delivery, matching contract,
different contract, matching setting, different setting. Order sources by that kind,
breaking ties by the original saved source order. Keep four sources and two relationships
per source. No additional matches, multi-hop traversal, question rewriting, filtering of
settings, source-name inference or confidence claim. Clue kind is a reading heuristic,
not proof that code links are relevant or configuration is unimportant.

Use the production v1 selector to establish eligibility and original evidence admission.
Reconstruct the bounded projection input and require exact equality with the real v1
candidate-link context before comparing the proposal. A source placed first can expose
its first admitted link without changing anchors; this provides a bounded eligibility
probe over at most twenty sources. Reorder only a copied source list, retaining the
original context, lexical scores, source identities and every input byte.

## Decision

regression blocks unconditional promotion even if the known library omission is fixed.
Do not hide or average away that counterexample. Any production change requires a

way to inspect omitted eligible sources may be a better follow-up than automatic ranking.
No corporate data, real-model request, new framework adapter or bridge acceptance is
authorized by this qualification. Existing failed semantic gates remain failed.
