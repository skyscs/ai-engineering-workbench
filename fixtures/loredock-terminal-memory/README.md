# Frozen terminal memory ownership protocol

Task 087 authors this fresh archive-intake family for one targeted ownership
diagnostic, after the independent tiny lifecycle works. It is not a repaired score
or a new qualification matrix. All earlier families remain exhausted. No application
parser, candidate or profiler has observed these bytes at freeze time. Pure UTF-8
construction/count/hash preflight is allowed; expectations are source-authored and
not blind. Do not import this directory from ordinary tests.

## Inputs and supported path

UTF-8 bytes and 21 expected facts**. Twenty README files and three JSON files account
for the non-code remainder. Inventory marker files add no function/operation/record
facts. `preflight.json` fixes the aggregate corpus hash and per-source counts/hashes.
`baseline.json` fixes implementation/dependency bytes; a later clean measured commit
identifies the entry point. Built service identities are recorded separately.

The desk has four supported Vue actions and one intentionally unresolved search.
The default first two actions each traverse a ten-node/nine-edge chain:
Vue action → imported TypeScript function → literal POST → JSON route → handler
reference → Java handler → publication → subscription → `onMessage` → Mongo write.
The default union is eleven nodes/ten edges; selection is ten/nine. Selection and
default captures reopen ten exact original spans; the isolated path is one node,
zero edges, one flow and five originals. Page offset four contains the isolated
search. All twenty sources remain dependencies, including uncited curation notes.
The complete typed ordered paths, edge kinds, roots, original spans and scope are

## One execution

Use pinned Linux Node 22.23.2 / V8 12.4.254.21-node.56 with no Node options/flags.
One preparer PID indexes/analyzes, closes and copies stopped data, reopens, and runs
first, repeat-1/2/3, selected, page-4, isolated, then two replacement analyses and
history after the initial analysis is evicted. Existing bounded pause/resume behavior
is unchanged. No operation retry, extra process arm, profile or larger application
limit is allowed. Preserve the original 5,000 ms, 1,000,000 work, 150 ms interval,
384 MiB sampled RSS, 64 MiB sampled heap growth and all output caps.

After all ordinary operations, export exactly `after-history` with services open.
Close services, release the owning stack, await another event-loop turn, then export
`after-release`. No manual GC, registry of observed objects or additional snapshot.
Expected corpus construction and graph decoding happen only after worker exit.

Each child file/snapshot is bounded at 128 MiB; each graph at 1,000,000 nodes,
4,000,000 edges and 1,000,000 strings. Eight frozen selectors name file-fact payloads,
path/analysis/catalog/Git services and SQLite database/statement wrappers. Each emits
at most eight examples and 64 path steps; summaries are at most 256 KiB. Missing
constructor matches do not establish absent native ownership. The worker watchdog
is 900 seconds; each of two separate offline parsers gets at most 60 seconds.
An outer 1,050-second watchdog bounds the whole invocation. Child RSS is sampled
every 10 ms with a 1 GiB stop threshold; continued missing RSS fails at 100 ms.
TERM is followed by KILL after one second. These diagnostic bounds are not application
acceptance limits or instantaneous kernel memory guarantees.

Record code/freeze/runtime/hardware identities and all first raw operations,
receipts, metadata, lifecycle endpoints, graph bytes, parser summaries, stdout,
stderr, exit/signal/stop details and partial files. Do not retry, tune limits/selectors,
repair an oracle, or replace the first result after observation. A failed operation
gate remains failed even if both graphs are complete. A failed/incomplete snapshot
is itself an outcome, not permission for another run.

## Interpretation and next decision

V8 snapshot generation collects garbage, blocks and allocates. The first export
perturbs the second. Report counts, shallow sizes and paths with runtime/weak/native
uncertainty; never treat these as retained subtree bytes, native RSS, leak proof or
ordinary shutdown savings. Source/usefulness/history, resources and terminal
completeness are independent results. This single intrusive lifecycle cannot qualify
streaming or promote production code.

After review, choose at most one supported next action. A concrete strong application
retainer may justify a separately scoped lifetime fix. If selected application
payloads/owners do not survive or paths are uncertain, report that result and make
one explicit decision about transient allocation/process residency. Do not introduce
a cache or compaction without evidence. Any later candidate needs a new complete
uninstrumented qualification under the unchanged application gates.
