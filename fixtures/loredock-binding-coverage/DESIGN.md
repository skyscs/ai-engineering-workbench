## Saved metadata proof and encoding

Read at most twenty source headers and 10,000 admitted tree entries in bounded pages. Match
every indexed supported code file to exactly one validated inventory unit. Reject duplicate/
foreign/missing identities, malformed rows and file/ancestor collisions. Read original facts
through the unchanged CodeAnalysis service. A ready source with zero path omissions must
reconstruct exactly to its recorded Git tree ID before absence can inform a binding.
Non-ready/omitted source coverage remains unknown. Symlinks/gitlinks are opaque; unsafe paths
are conservative source blockers. Do not fetch Git objects or walk repositories during reads.

Canonical metadata rows use UTF-8 length-prefixed fields, avoiding JSON-escape assumptions.
Start each row with ASCII `S` or `F`; each non-null field is `decimalByteLength:value`, null is
`-1:`, and each row ends with LF. Integers use their ordinary base-ten representation.

- Source fields: `sourceId, name, revision, tree, status, omitted`, ordered by source ID.
- File fields: `id, sourceId, path, mode, blob, size, status, reason, contentHash`, ordered by
  source ID, path and ID under SQLite BINARY order.

The sum of these exact row bytes is bounded at 8 MiB, checked using aggregate byte lengths
before loading rows. Stream the canonical digest; include it in generation identity and
recheck the digest/manifest/source-policy identity before publication. Root node identities
bind that generation; explicit root reads must provide its generation ID. Integrity/scope/
cancel/resource failure returns no pending graph, fact vector or consumed source identifiers.

Tree proof uses canonical Git tree bytes, mode spelling, raw object IDs, UTF-8 byte sorting
with directory terminators and the recorded SHA-1/SHA-256 format. Four independent vectors
were generated with system Git before implementation: empty and mixed trees for both hash
formats. Mixed trees include executable, symlink/gitlink, Unicode and reserved-name paths,
and file/directory sort neighbors. Retain these expected IDs without recomputing the oracle
with the candidate. A changed/missing tree entry must fail rather than become known absent.

## Protocol and decision

that refuses overwrite. Record every first observation immediately with its exact byte/hash
identity; execute only the declared repeats. Retain normalized stderr/exit status and harness
failures. Preparation/indexing/analysis are outside projection timing; no heavy local checks

All correctness/boundary checks and all eight base resource observations must pass. Losing
useful paths, masking relevant alternatives, exceeding a resource target or a harness failure
rejects promotion. Retain failures without changing the frozen oracle or replacing the run.

runtime acceptance and does not switch existing graph/answer/review consumers.
